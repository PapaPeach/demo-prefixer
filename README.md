# Demo Prefixer
A simple program designed to automatically replace the prefix of a recorded demo file with the map name the demo was recorded on.  
The program's main purpose is to be a simple-ish program for me to test and compare different programming languages, currently Go.

# Installation
- Download the latest release from the [Releases page](https://github.com/PapaPeach/demo-prefixer/releases).
- Put demo-prefixer.exe in a folder containing demo (.dem) files you'd like to prefix.
- Run demo-prefixer.exe and answer any prompts it gives you.
